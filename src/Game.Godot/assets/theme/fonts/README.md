# 字体映射

UI 和场景只引用本目录中的语义字体资源，不直接引用 `assets/font` 下的具体字体文件。

- `default_ui_font.tres`：常规界面、正文、按钮和输入框。
- `martial_display_font.tres`：战斗技能名、奥义演出和武侠风格标题。

更换字体时，只修改相应 `.tres` 的 `base_font`。不要逐个修改场景，也不要在业务代码中加载字体路径。

更换默认字体后，应在目标导出平台核对：

- 项目现有文本中的汉字、英文、数字、标点和特殊符号是否完整。
- 明确承诺支持的玩家输入与 MOD 内容字符范围是否完整；只有计划支持繁体内容时，才要求覆盖繁体中文。
- 固定高度按钮、单行裁剪标签、大字号标题是否发生截断或溢出。
- 对话、选项和提示框的自动换行与自动缩放是否仍然可读。
- Godot 字体导入设置及实际导出包是否一致；不要依赖开发机的系统字体回退来掩盖缺字。
